# SQL - Introduction

This project contains introductory MySQL scripts for listing and managing
databases, creating and inspecting tables, and querying and updating records.

The scripts are intended to be run with MySQL 8.0. Select a database on the
command line for scripts that operate on the current database, for example:

```sh
mysql -uroot -p hbtn_0c_0 < 4-first_table.sql
```

Scripts `0-list_databases.sql` and `1-create_database_if_missing.sql` and
`2-remove_database.sql` do not require a selected database.
