=======================
How to Use 1-my_list.py
=======================

This module defines a class ``MyList`` that inherits from ``list``.

Instantiation
=============

``MyList`` can be instantiated with no arguments, returning an empty list:

::

    >>> MyList = __import__('1-my_list').MyList
    >>> my_list = MyList()
    >>> type(my_list)
    <class '1-my_list.MyList'>
    >>> print(my_list)
    []

Or with a single iterable argument:

::

    >>> my_list = MyList([1, 2, 3])
    >>> print(my_list)
    [1, 2, 3]

``print_sorted`` Method
=======================

``print_sorted()`` prints the list in ascending order without modifying the original list:

::

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Works with negative numbers:

::

    >>> my_list = MyList([-5, 10, -1, 0])
    >>> my_list.print_sorted()
    [-5, -1, 0, 10]

Works with an empty list:

::

    >>> empty = MyList()
    >>> empty.print_sorted()
    []
